Enable Developer Options & USB Debugging

Setup

On your Android device, you need to enable developer options and USB debugging to allow communication with your computer.

Step-by-Step Activation:

Settings → About Phone

Tap "Build Number" 7 times

Developer Options

Enable "USB Debugging"

  1. Go to Settings → About Phone
  2. Find Build Number and tap it 7 times
  3. Return to Settings, enter Developer Options
  4. Enable OEM Unlocking (if available)
  5. Enable USB Debugging

Warning: Some carrier-locked devices may not have the "OEM Unlocking" option. These devices cannot install GrapheneOS.

Phase 3: Install GrapheneOS

5

Flash GrapheneOS Factory Image

Installation

This is the main installation process where you'll flash GrapheneOS to your device using fastboot commands.

$ cd ~/platform-tools
$ ./fastboot devices
0A2B3C4D5E6F fastboot
$ ./fastboot flashing unlock
<waiting for device>
Use volume and power keys to confirm unlock...

Important: The exact flashing commands vary by device. Always check the official GrapheneOS installation guide for your specific device.

6

Tip: GrapheneOS includes a "Sandboxed Google Play" compatibility layer that allows running Google Play Services in a restricted sandbox without giving them full system access. Only enable this if absolutely necessary.

Phase 2: Unlock Bootloader

1

Connect Device & Test ADB

Connection

Connect your Pixel device to your computer via USB and test the ADB connection.

$ adb devices
List of devices attached
0A2B3C4D5E6F unauthorized
$ # Check your phone for authorization prompt
$ adb devices
0A2B3C4D5E6F device

Troubleshooting: If your device doesn't appear, try different USB cables/ports, reinstall drivers (Windows), or check if USB debugging is enabled.

2

Reboot to Bootloader & Unlock

Destructive

This step will wipe your device. Make sure you have completed all backups!

$ adb reboot bootloader
Rebooting to bootloader...
$ fastboot flashing unlock
❗️ This will erase all data on your device
Use volume keys to select "Unlock" and power to confirm

Irreversible: Unlocking the bootloader will wipe your device completely. There's no going back without losing all data.

Note: On some Pixel devices, you may need to use fastboot flashing unlock_critical for full partition access.

Configure GrapheneOS Security Features

Optimization

GrapheneOS includes powerful security features that you should configure for maximum protection.

  • Enable "Install unknown apps" only for trusted app stores
  • Configure USB-C port control (Settings → Security → USB-C port)
  • Set up a firewall to block internet access for unnecessary apps
  • Review app permissions and disable unnecessary ones
  • Use camera/microphone indicators to detect unauthorized access
  • Enable automatic security updates

    • Advanced: For maximum security, enable GrapheneOS's "Hardened malloc" and "Memory tagging" features in developer options.

    Troubleshooting & Support

    Common Issues & Solutions

    Device not detected by ADB
    • Try a different USB cable (some cables are power-only)
    • Try different USB port (preferably USB 2.0)
    • Reinstall USB drivers (Windows)
    • Restart ADB server: adb kill-server && adb start-server

    Bootloader won't unlock
    • Ensure "OEM Unlocking" is enabled in Developer Options
    • Carrier-locked devices cannot be unlocked
    • Some devices require being connected to internet first

    Flashing fails
    • Ensure you have the correct factory image for your device
    • Check that you're using the latest platform-tools
    • Some devices require unlocking critical partitions
