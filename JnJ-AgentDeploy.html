Deployment: Install the Workers

This is the technical guide. Give this to Joaquín and Alejandro. They don't need to understand the code. They just need to follow the steps.

Step 1: Install Docker

Most of these agents run in Docker containers. It's a way to run software without messing up your computer.

Download Docker Desktop from docker.com. Install it. Open it. Leave it running in the background.

Step 2: Deploy OpenCloser (The Sales Agent)

This is the AI that will hunt leads and make calls for you.

# Open your terminal (Command Prompt on Windows, Terminal on Mac) # Run these commands one by one: git clone https://github.com/issacops/opencloser-v2.git cd opencloser npm install npm run tauri dev

Once it opens, click "Demo Mode" to see it work without any API keys. Then, add your Gemini API key (free from Google AI Studio) to enable real AI.

Step 3: Deploy ShapelessAI (The Social Media Agent)

This agent will schedule and post your content automatically.

# Install the Shapeless CLI npm install -g shapeless # Log in (you'll need a free account from shapelessai.com) shapeless login # Connect your Instagram, TikTok, and Facebook accounts shapeless connections # Schedule a post shapeless posts create --to --text "The adventure of a lifetime awaits in Colombia. Link in bio." --queue

Step 4: The Morning Routine

Every morning, the boys do this:

  1. Open OpenCloser. Check the leads the AI found overnight.
  2. Approve the follow-up messages.
  3. Open Shapeless. Check the posts scheduled for the day.
  4. Record one raw video on their phone. Upload it. Let the AI write the captions.
  5. Go ride ATVs. The agents work while they play.
