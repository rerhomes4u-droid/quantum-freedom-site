03The Code Word System

The code word is not written down in this document. The protocol is. The words themselves are held by the Response Team Lead and the member. They are rotated quarterly. They are burned if compromised.

Code Word Protocol — Internal Only

1. Selection Criteria

The code word must be:

  • One word, 3–8 letters
  • Easy to pronounce over a degraded phone line
  • Phonetically distinct from common words
  • Not emotionally charged if overheard
  • Not a homophone of another word (write/right, there/their)

These criteria are drawn from spoken-word verification protocols used in high-risk communication systems [citation:3]. The word must be recognizable even if the line is bad, and it must not cause alarm if someone else hears it.

2. Issuance

Each member is issued:

  • One primary code word — means "I am in danger, activate the extraction protocol"
  • One duress code word — means "I am being coerced, do not act on the primary word, verify through the secondary channel first"

The words are issued in person or through a secure channel. They are never sent by text, email, or any written medium. The member memorizes them. The Response Team Lead memorizes them. They are not stored in any digital system.

3. Dry Run

Before the system goes live, the member and the Response Team Lead conduct a dry run. The member sends the primary code word through the agreed channel. The Lead verifies identity through the secondary channel. The Lead confirms the dry run is complete. The member is told: "Your code word works. If you send it for real, we will act."

4. Rotation

The code words are rotated every 90 days. The old words are burned. The new words are issued in person or through a secure channel. The rotation is documented in the internal log, but the words themselves are never written.

5. Burn Procedure

If a code word is compromised—if the member suspects it has been discovered, if the member's phone is seized, if the member is detained—the word is burned. The member sends a pre-arranged signal (a different word, a different channel) that means "burn the words." The Lead burns the words. The member is issued new words as soon as it is safe.

6. The Duress Word

The duress word is the most important part of the system. If a member is forced to send their primary word by someone who is threatening them, they send the duress word instead. The Lead receives the duress word and knows: the member is in danger, but the danger is not what it appears to be. The Lead does not activate the extraction protocol. The Lead verifies through the secondary channel first. If the secondary channel confirms the duress, the Lead escalates to the trustees and to the attorney.

7. What the Code Word Is Not

The code word is not a password. It is not a key. It is not a legal document. It is a signal that activates a human protocol. The protocol is the protection. The word is only the trigger.

WARNING: The code word system is only as strong as the people who hold the words. If the Response Team Lead is compromised, the system is compromised. The Lead must be someone the member trusts with their life. The Lead must have a backup. The backup must have a backup.
